# PRD — 越南家人在台灣生活 part 2：就醫溝通卡＋匯率到價提醒

## 背景
越南家人在台灣兩個高壓場景：
1. **看醫生／買藥**：中文不流利，症狀說不清楚，掛號不知道掛哪科。
2. **匯錢回越南**：匯率天天變，想等到好價位再匯，但不可能整天盯著看。

## F1 就醫溝通卡 🏥

### 使用者故事
她用越南語說「làm thẻ khám bệnh: tôi bị đau đầu 2 ngày, sốt 38 độ, dị ứng penicillin」
（幫我做就醫卡：頭痛兩天、發燒38度、對青黴素過敏）→ bot 回一張**給醫護人員看的中文卡**：

```
🏥 就醫溝通卡（請出示給醫護人員）
您好，我是越南籍人士，中文不太流利，請多包涵。
【症狀】頭痛兩天、發燒 38 度
【過敏／備註】對青黴素（penicillin）過敏
麻煩您了，謝謝！
──────────
（越南語回譯，讓她確認卡片內容沒翻錯）
```

### 規格
- **卡片模板寫死在程式裡**（開場、結尾、分隔線固定），AI 只負責把「症狀描述」
  翻成中文＋回譯確認——降低 AI 亂發揮的風險。
- 觸發方式：
  - 關鍵字（一對一）：`就醫卡 <症狀>`、vi：`khám bệnh <症狀>`／`thẻ khám bệnh <症狀>`
    （只打關鍵字沒帶症狀 → 用她的語言引導「請描述症狀」）。
  - AI 工具 `make_medical_card(symptoms)`：任何語言的自然語句（「幫我做看醫生的卡」）都能觸發。
- 翻譯失敗（AI 掛）→ 用她的語言回「暫時無法製作，請稍後再試」（不能出半張卡）。
- 任何語言輸入的症狀都翻成中文卡（不只越南語；中文輸入則直接進卡＋越語回譯可省略）。

## F2 匯率到價提醒 💱

### 使用者故事
她打「báo tỷ giá 850」（或中文「匯率提醒 850」）→ bot 記住「1 TWD ≥ 850 VND 時通知我」
→ 之後某天到價，bot 主動推播（用她的語言）：「🔔 到價了！現在 1 TWD = 851.2 VND」。

### 規格
- 固定幣別對 **TWD→VND**（家庭場景唯一剛需；其他幣別對不做）。
- 方向自動判斷：目標 > 現價 → 漲到通知；目標 < 現價 → 跌到通知。設定時回覆要講清楚
  （「現在 842，會在 ≥850 時通知你」，用她的語言）。
- **每人一筆**（新設定覆蓋舊的）；**到價即推播並自動移除**（一次性）。
- 指令：設定 `匯率提醒 <數字>`／`báo tỷ giá <數字>`；取消 `清除匯率提醒`／`xóa báo tỷ giá`；
  查看 `匯率提醒`（不帶數字）→ 顯示目前設定或「沒有設定」。
- AI 工具 `set_rate_alert(target)`（任何語言自然語句：「匯率到 850 跟我說」）。
- 排程：自我排程 setTimeout（比照 reminder/morning 的防重入模式），每 30 分鐘檢查一次
  （匯率 API 本身有 30 分快取、來源每日更新，頻率足夠）；比對成功 → push（她的語言）→ 移除。
- 存 `data/rateAlert.json`；Render 重啟會清空（已知限制，與提醒同級，可接受）。
- API 取不到匯率時該輪跳過（不誤刪、不誤報）。

## 不做（範圍外）
- F1 不做多輪問診、不做科別建議 AI 診斷（卡片尾句固定「請問需要掛哪一科？」由醫護回答）。
- F2 不做多幣別、多筆提醒、重複性提醒（到價一次即除）。
- 群組內不觸發這兩個功能（維持群組只翻譯）。

## 驗收條件（可測）
1. **就醫卡（stub ai.ask）**：`khám bệnh đau đầu 2 ngày` → 回覆含 `🏥`、固定開場「越南籍」、
   stub 的中文症狀譯文、分隔線與 stub 的越語回譯；`就醫卡 頭痛兩天` → 中文卡正常；
   只打 `khám bệnh` 無症狀 → 越南語引導句；ai.ask 回空/丟例外 → 她的語言的「暫時無法」句、無半張卡。
2. **就醫卡 AI 工具**：`tools.run(uid,'make_medical_card','{"symptoms":"..."}')` 回卡片字串。
3. **到價提醒設定（stub getRate）**：現價 842 時 `báo tỷ giá 850` → 確認句含 850 與「≥／漲到」語意
   （vi 使用者收 vi 句）；`匯率提醒 800` → 「跌到」語意；`匯率提醒` 無數字 → 顯示現有設定；
   `清除匯率提醒` → 確認移除；data/rateAlert.json 寫入/清除正確（每人一筆，覆蓋驗證）。
4. **到價觸發（stub getRate + stub push）**：設 850、stub 現價 851 → tick 一輪 → push 一次
   （內容含 851、使用者語言）且該筆被移除；現價 848 → 不 push 不移除；getRate 回 null → 跳過不誤刪。
5. **AI 工具**：`set_rate_alert` 設定成功回英文摘要（模型轉述）；防重入：tick 執行中再觸發不重複。
6. **不回歸**：既有匯率查詢「匯率 台幣 越南盾」照舊；提醒/早安排程不受影響；群組訊息不觸發新功能。
7. `node --check` 全變更檔。
