# PRD — 🌀 防災警報推播（颱風／地震／豪雨等，越南語版）

## 背景
台灣的緊急警報（颱風警報、地震報告、豪／大雨特報、淹水、土石流…）幾乎都是中文，
越南家人看不懂、可能錯過避難時機。目標：官方警報一發布，bot 主動推播給訂閱者，
**用他的語言**（越南語優先），讓不懂中文的家人也能即時掌握。

## 目標
1. 訂閱制：`開啟警報`／vi `bật cảnh báo`（開）、`關閉警報`／`tắt cảnh báo`（關）；預設關（opt-in）。
2. 背景輪詢官方**免金鑰**警報源（架構師實測驗證），偵測到**新的、有意義的**警報就推播；
   已推過的不重複（去重 id 持久化，重啟不重發）。
3. 依訂閱者語言推播（AI 把中文警報翻成其語言）；**安全優先**：翻譯失敗時仍推原始中文＋一句
   「(自動翻譯失敗，以下為原文)」提示——警報絕不因翻譯失敗而漏發。
4. 全程免新金鑰優先（若唯一可靠來源需免費金鑰，如中央氣象署 CWA，才用，並提供設定指引）。

## 範圍（要做）
### F1 資料源（架構師實測擇一，關鍵風險）
候選：
- **A. NCDR 民生示警公開資料**（災害示警平台 alerts.ncdr.nat.gov.tw 的 CAP/ATOM 聚合 feed）：
  聚合颱風/地震/豪雨/淹水/土石流等多機關警報，**可能免金鑰**——需實測 feed URL、格式（CAP XML/ATOM/JSON）、
  是否含 id/發布時間/嚴重度/生效區域、更新頻率、雲端 IP 是否可達。
- **B. 中央氣象署 CWA 開放資料**（opendata.cwa.gov.tw：天氣特報 W-C0033-001、地震 E-A0015/E-A0016）：
  權威但需免費 Authorization 授權碼（註冊取得）。
架構師須**真實 fetch 驗證**擇一，寫進 DESIGN（含樣本記錄、欄位名、去重鍵、嚴重度欄位）。

### F2 警報服務（新 service，比照 rateAlert/tutor 排程模式）
- 輪詢間隔架構師定（建議 5–10 分鐘；免費額度/禮貌）；自我排程 setTimeout＋ticking guard。
- **去重**：記錄已推播的警報 id（＋更新時間，若同 id 有升級版本可再推）到 `data/alert-state.json`（經 store 門面持久化）。
- **嚴重度／類別過濾**：只推「有意義」的（颱風警報、地震顯著有感、豪雨/大雨特報、淹水/土石流警戒…），
  過濾掉低價值訊息避免洗版（門檻由架構師依 feed 欄位定，寫進 DESIGN）。
- 推播內容：類別 emoji＋標題＋生效區域＋時間＋（可行則）簡短說明；AI 翻成訂閱者語言。
- 首次啟用（state 空）時**不回補歷史**——只推啟用後「新出現」的警報，避免一開機灌一堆舊警報。

### F3 指令與提示
- 開關指令（中／越）；`警報` 或 `bật cảnh báo` 無誤觸（錨定）；確認訊息依語言。
- helpMenu 加一行（🌀 警報推播）。
- 不加 AI 工具（確定性指令）。

## 不做（範圍外）
- 不做逐縣市精細訂閱（v1 推全國性＋顯著警報；區域欄位若 feed 有，可顯示但不做個人化過濾）。
- 不做歷史查詢、不做地圖。不改既有排程。

## 驗收條件（可測；資料源一律用「本機 mock feed」測，不需真連）
1. **解析器純函式**：`parseAlerts(rawFeed)` → 標準化陣列 `[{id, category, severity, title, area, effective, ...}]`；
   壞格式/空 → `[]` 不 throw；嚴重度/類別過濾正確（給定含「豪雨特報」「大雷雨即時訊息(低)」的樣本，
   只留該留的）。
2. **去重**：同一批 feed 連續兩輪 → 第二輪 0 新警報；state 記錄正確；新 id 出現 → recognized as new。
3. **首次啟用不回補**：state 空 + feed 有 3 筆 → 標記全部為已見但**不推播**（或依 DESIGN 決策：僅記錄不推）；
   之後新出現第 4 筆才推。（架構師定義精確語意並寫進 DESIGN。）
4. **推播＋翻譯**（stub ai.ask + stub pushMessage）：新警報 → 每訂閱者依語言收到一則（vi 收越南語譯文）；
   ai.ask 失敗 → 推原始中文＋失敗提示（**不得漏發**）。
5. **訂閱指令**：`開啟警報`/`bật cảnh báo` → 確認（各語言）＋寫入訂閱；`關閉警報`/`tắt cảnh báo` → 移除；
   未訂閱者不收。
6. **排程**：tick 防重入；輪詢失敗（mock 500/逾時）→ 該輪跳過不誤標記、不 crash；下輪正常。
7. `store.js` KNOWN_KEYS 加 `alertSub.json`、`alert-state.json`；node --check 全過；既有功能不回歸；
   測試不 require index.js、不 .start()、結尾 process.exit(0)、data/ 備份還原。
